# Review checklist (weekly or monthly)

1. Run `python3 scripts/vault_lint.py <vault>` and fix every error.
2. Orphans: link each to a MOC, or archive it.
3. Duplicates: merge into one note, keep the richer one, leave no stale copy.
4. Stale facts: check dates, statuses and names in project and user notes.
5. Inbox: file or delete everything in `00_Inbox`.
6. MOCs: any theme with 5+ notes and no hub? Create one.
7. Finished projects: move to `_Archive`, keep the MOC link.
8. Rebuild the index: `python3 scripts/build_index.py <vault>`.
