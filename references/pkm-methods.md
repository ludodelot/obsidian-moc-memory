# PKM methods and what suits an AI agent

| Method | Idea | Fit for agents |
|---|---|---|
| MOC (Maps of Content) | Hub notes that link a theme | Best: a small entry point that scopes context before search |
| Zettelkasten | Atomic notes, dense links | Good: one fact per note retrieves cleanly |
| PARA | Projects, Areas, Resources, Archive | Good for top-level folders; weak inside dense topics |
| Johnny.Decimal | Numbered areas and IDs | Good for stable navigation; rigid for fast capture |
| Daily notes / logs | Chronological capture | Good as inbox; needs periodic distilling into topic notes |

Default recommendation: PARA-like top folders, atomic notes, MOCs as the navigation layer, an index file for session start. Always defer to the user's existing habits.
