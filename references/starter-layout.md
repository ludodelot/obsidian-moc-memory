# Starter layout (adapt to the user)

```
Vault/
├─ _INDEX.md            auto-generated index, one line per note
├─ 00_Inbox/            quick capture, emptied on review
├─ 01_Projects/         active work, one MOC per big project
├─ 02_Areas/            ongoing responsibilities
├─ 03_Reference/        stable knowledge and external pointers
├─ 04_Memory/           user, feedback notes the agent relies on
├─ 05_Logs/             weekly recaps, decisions
├─ MOCs/                MOC-<Theme>.md hubs
└─ _Archive/            finished or stale, never deleted
```

Naming: follow the user's detected style. If none, use `Title Case With Spaces` for notes, `MOC-Theme` for hubs, `YYYY-Www-recap` for logs.
Minimum frontmatter: `type`, `description`, `created`.
